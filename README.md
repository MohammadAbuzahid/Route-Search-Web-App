## Project Description
A web application that finds routes between cities using:
- BFS
- DFS
- UCS
- Greedy Best-First Search
- A* Search

The application shows:
- Path
- Total cost in km
- Number of steps
- Comparison between all algorithms

## How to Run

1. Install dependencies:
   npm install

2. Run the project:
   npm run dev

3. Open the local URL shown in the terminal.
